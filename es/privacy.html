Política de Privacidad

Esta página explica qué información recopila este sitio web, por qué, y cómo se trata. Última actualización: agosto de 2026.

Este es un resumen en lenguaje claro, ofrecido de buena fe, y no sustituye el asesoramiento legal. Si tienes inquietudes legales específicas sobre el cumplimiento de la protección de datos, consulta a un profesional cualificado.

1. Quién es responsable

Este sitio web (thechestnuttree.org) está gestionado por The Chestnut Tree — El Castanyer, Can Ramonet, Sant Joan de Sanata, Llinars del Vallès, Barcelona, España. Para cualquier pregunta sobre esta política o tus datos, contáctanos en info@thechestnuttree.org.

2. Qué datos recopilamos

Solo recopilamos datos que tú decidas activamente darnos:

  • Formularios de contacto y solicitud de visita — nombre, dirección de correo, teléfono (si se proporciona), tu mensaje y, para solicitudes de visita, la edad de tu hijo y las fechas preferidas. Se utiliza únicamente para responder a tu consulta, organizar una visita, o procesar una solicitud de admisión o de empleo/voluntariado.
  • Registros técnicos estándar — como prácticamente todos los sitios web, nuestro proveedor de alojamiento registra automáticamente información técnica básica (como la dirección IP y el tipo de navegador) con fines de seguridad y fiabilidad.

3. Servicios de terceros que utiliza este sitio

Para mantener este sitio web simple y fiable, dependemos de un pequeño número de servicios externos, cada uno de los cuales puede procesar datos técnicos limitados bajo sus propias políticas de privacidad:

  • GitHub Pages (GitHub, Inc.) — aloja y sirve este sitio web.
  • Formspree — procesa los envíos de nuestros formularios de Contacto y Reserva de Visita.
  • YouTube (Google) — utilizado en modo de privacidad mejorada para incrustar vídeos de testimonios en nuestra página de Testimonios.
  • Google Fonts — carga las tipografías utilizadas en este sitio.
  • Cloudflare Web Analytics — nos proporciona estadísticas anónimas y agregadas sobre las visitas al sitio (como las páginas vistas y los sitios de referencia) para que podamos entender cómo la gente encuentra y utiliza este sitio web. No utiliza cookies ni te rastrea en otros sitios web.

No utilizamos seguimiento publicitario, y no vendemos ni compartimos tus datos con terceros con fines de marketing.

4. Base legal y conservación

Procesamos los datos que envías basándonos en tu consentimiento y nuestro interés legítimo en responder consultas y gestionar la escuela. Conservamos los datos de consulta solo mientras sea necesario para atender tu solicitud.

5. Datos de menores

Este sitio web está pensado para padres, tutores y educadores, no para el uso directo por parte de menores. Cuando un formulario pide la edad de un hijo, lo proporciona el padre o tutor solo con fines de admisión o planificación de visitas.

6. Tus derechos

Según la ley de protección de datos de la UE/España (RGPD), tienes derecho a acceder, corregir, eliminar o restringir los datos que tenemos sobre ti. Para ejercer cualquiera de estos derechos, escribe a info@thechestnuttree.org. También tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

7. Cambios en esta política

Podemos actualizar esta página de vez en cuando a medida que cambien el sitio web o los servicios que utiliza.
